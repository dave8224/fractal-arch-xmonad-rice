# Fractal Desktop — Arch Linux XMonad Rice

Custom XMonad desktop configuration for the Fractal Desktop running Arch Linux.

## Desktop Setup
- OS: Arch Linux
- Window Manager: XMonad
- Display Manager: LightDM with Slick Greeter
- GPU: NVIDIA GeForce RTX 2060 SUPER
- Monitor: 2560x1440
- Theme: Tokyo Night

## Components
- XMonad with custom Super keybindings and window gaps
- Tokyo Night Polybar with Arch logo and workspaces
- Polybar volume control and Rofi power menu
- Tokyo Night Rofi launcher
- Picom compositor for transparency
- Alacritty with JetBrainsMono Nerd Font and 88% opacity
- Custom Oh My Posh prompt
- Custom XMonad wallpaper
